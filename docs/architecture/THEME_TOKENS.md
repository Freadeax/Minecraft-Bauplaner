# UI-01 Theme-Kern

Implementiert: fünf rein visuelle Themen (Modern, Medieval, Industrial, Fantasy, Nether), drei Erscheinungsmodi (dark, light, system), sichere Normalisierung, Abstände, Radien und Kontrastberechnung. Alle Funktionen sind unabhängig von Browser-APIs und Voxel-/Materialdaten.

Die Testdatei `tests/theme-tokens.test.mjs` prüft Rückfallwerte, Kontrast von mindestens 4,5:1, Erscheinungsmodus und Unveränderlichkeit der Tokens.

**Nicht implementiert:** React-/CSS-Einbindung, UI-Umschalter, Persistenz, mobile Layouts. Kein zusätzliches Repository, keine Registry, keine produktive Anmeldung.
